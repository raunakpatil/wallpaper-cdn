# wallpaper-cdn

Static image host for **wallpaper-app-android**, served by GitHub Pages at https://raunakpatil.github.io/wallpaper-cdn/

- Layout: `w/<id>/thumb.webp`, `preview.webp`, `full.webp`, optional `original.jpg|png`
- Files are committed by the Supabase Edge Function `upload-wallpaper` (dashboard uploads). **Don't edit by hand.**
- All images are licensed individually (see the app database); they are **not** free to reuse.
